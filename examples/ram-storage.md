Explain RAM versus storage to a beginner choosing a computer, in English, using a desk and filing cabinet analogy. Target seven scenes and 155–175 spoken words, around 60–90 seconds.

Reference notes:
- RAM is fast working memory for programs and data currently in use.
- Ordinary system RAM is volatile: its contents are lost when power is removed.
- Persistent storage (such as an SSD) retains saved files and installed applications without power.
- Opening a program loads the needed code/data into RAM. Saving writes changes to persistent storage.
- More RAM helps when the active workload does not fit in existing memory; it does not make every task faster.
- More storage capacity lets you keep more files; capacity and speed are separate properties.
- Both commonly use gigabytes as units but perform different roles. Avoid numeric specifications and speed ratios.
- Desk = working space; cabinet = saved materials. This is a simplified analogy, not a literal account of all operating-system behavior.

Use comparison scenes with paired headings and concise bullet points, plus flow scenes for opening and saving a document. Preserve the distinction between unsaved work and saved files.
